# HDFS-14370. Add exponential backoff to the edit log tailer to avoid spinning on empty edit tail requests

## Commit
- Hash: f6ce2f4a508（2019-07-24）
- 文件: DFSConfigKeys.java, EditLogTailer.java, hdfs-default.xml, ObserverNameNode.md, TestEditLogTailer.java

## Diff 机制分析
SBN/Observer 的 EditLogTailer 在没有新事务时按固定周期向 JN 发起 selectInputStreams/tail 请求形成空转。patch 增加指数退避：连续空 tail 时逐步拉长间隔（上限可配，默认 2x 至最大 120s 一类），有新事务立即恢复；新增 `dfs.ha.tail-edits.backoff` 相关配置。

## 影响评估
中。大集群多 SBN/Observer 时显著降低 JN 空 tail 请求的 RPC 压力（原来每 NN 每周期都轮询）。行为变化是 tail 延迟在静默期变长，对 failover RPO 有一定影响（有界，受最大退避限制）。冲突在 EditLogTailer.java，需手工合并。
