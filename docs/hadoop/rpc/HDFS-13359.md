# HDFS-13359. DataXceiver hung due to the lock in FsDatasetImpl#getBlockInputStream

## Commit
- Hash: f2007818fc9（2019-08-09）
- 文件: FsDatasetImpl.java（1 行修改）

## Diff 机制分析
`getBlockInputStream` 在持有 FsDatasetImpl 全局读锁的情况下打开块文件输入流；打开涉及磁盘 IO，高负载或坏盘时长时间持锁，阻塞所有其他需要该锁的块操作（含写），DataXceiver 线程池耗尽表现为 DN 挂死。patch 把 input stream 的创建移到锁外（1 行）。

## 影响评估
高。一行修复真实挂起：锁内 IO 是典型的"锁不是保护资源而是保护快速临界区"违规，坏盘场景可放大成 DN 全面挂死。必须 cherry-pick。
