# HDFS-15725 — Lease Recovery never completes for a committed block which the DNs never finalize

## Commit

- **Hash**: `e7df47c45c0`
- **日期**: 2020-12-14
- **涉及文件**: `hadoop-hdfs/.../namenode/FSNamesystem.java`（+20/-20）；测试 `TestLeaseRecovery`

## Diff 机制分析

租约恢复（lease recovery）流程中，块已 COMMITTED 但 DN 因故障从未 finalize 该块时，旧的恢复逻辑在等待/要求 DN 上报 finalize 结果上陷入循环，租约永远恢复不完，文件一直 UC 状态不可访问。修复调整 `FSNamesystem` 中 lease recovery 对已提交但未 finalize 块的收尾逻辑：不再依赖 DN 的 finalize 上报，直接以 NN 侧已知的块长度完成恢复并关断文件。

## 影响评估

**中**。触发后表现为文件永久卡在 recoverLease，客户端无法读写该文件；频率低但后果是数据不可用，正确性修复。

## apply 检查结果

**冲突**：`FSNamesystem.java` patch does not apply；`TestLeaseRecovery.java` 同样冲突（与 3.1.1 基线漂移较大，需人工合入）。
