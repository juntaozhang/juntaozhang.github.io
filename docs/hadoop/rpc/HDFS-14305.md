# HDFS-14305. Fix serial number calculation in BlockTokenSecretManager to avoid token key ID overlap between NameNodes

## Commit
- Hash: 8fc4e406ad5（2019-09-30）
- 文件: BlockTokenSecretManager.java, TestBlockToken.java, TestFailoverWithBlockTokensEnabled.java

## Diff 机制分析
BlockTokenSecretManager 的 key serial number 由 NN 本地时间戳派生，HA failover 后新老 NN 可能算出重叠的 key ID，导致已颁发的 block token 被误认过期/无效或新旧 key 互相覆盖。patch 修正 serial number 的生成方式，保证跨 NN 唯一。

## 影响评估
中。影响开启 block token（默认开启）的 HA 集群：failover 窗口内 DN/客户端可能遇到 token 验证失败引发读写异常。属于正确性修复，建议 HA 集群 cherry-pick。
