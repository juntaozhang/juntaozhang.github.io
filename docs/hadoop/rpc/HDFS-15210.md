# HDFS-15210 — EC: File write hanged when DN is shutdown by admin command

## Commit

- **Hash**: `379a7a57267`
- **日期**: 2020-04-29
- **涉及文件**: `hadoop-hdfs-client/.../DFSStripedOutputStream.java`、`StripedDataStreamer.java`

## Diff 机制分析

EC 写路径上，admin 用 `shutdownDatanode` 关闭 DN 时 DN 会等待重启（datanode restart timeout 默认数分钟）而不是立即死；旧代码 `markExternalErrorOnStreamers` 把这类"等待重启"的 streamer 计入 failed 集合，`checkStreamerFailures` 里 `newFailed` 非空就触发失败处理，与 wait-for-restart 语义冲突，最终使写流程在 close 阶段挂起。修复两处：1) 处于 `doWaitForRestart()` 状态的 streamer 不再视为 failed，移出 failed 集合并保留在 healthy 集合；2) `checkStreamerFailures` 在有新 failed streamer 时 sleep `datanodeRestartTimeout`，给重启 DN 留恢复窗口。

## 影响评估

**高**。这是 EC 客户端写挂起（永久卡死）的修复，运维执行 DN 滚动重启/shutdown 时极易触发；对 EC 集群是稳定性必修项。

**clean**。
