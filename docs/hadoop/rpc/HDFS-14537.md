# HDFS-14537. Journaled Edits Cache is not cleared when formatting the JN

## Commit
- Hash: 3ba7826d41e（2019-06-18）
- 文件: qjournal/server/Journal.java（+16/-8）

## Diff 机制分析
JN 被重新 format 后，JournaledEditsCache（Edit Tail Fast Path 的内存缓存）中的旧事务未被清空，新旧数据混合，tail 请求可读到 format 之前的事务。patch 在 format 流程中清空 cache 并重置缓存区间。

## 影响评估
低。影响 JN format 后重新接入的场景（误操作恢复、重建 JN），缓存不清理会造成 SBN tail 到脏数据。修复小，但冲突在 Journal.java（取决于 3.1.1 是否已有 JournaledEditsCache——没有，属 fast path 系列），需手工合并；不使用 SBN read fast path 的集群不命中。
