# HDFS-14913 — Correct the value of available count in DFSNetworkTopology#chooseRandomWithStorageType()

## Commit

- **Hash**: `9067a11b0d048e76026c4a4eb28d9333dfd75f66`
- **Date**: 2019-10-21
- **涉及文件**: `hadoop-hdfs/.../net/DFSNetworkTopology.java`（+测试）

## Diff 机制分析

chooseRandomWithStorageType 计算候选 availableCount 时，对 excludedNodes 的
scope 前缀判断用 `startsWith(excludedScope)` 裸字符串比较：
`/rack1` 会误匹配 `/rack11`，把不在排除范围的节点从计数中扣掉，
availableCount 偏小，极端时剩 0 个候选直接抛 NoNodeToChooseException，
放置失败。修复：新增 `isNodeInScope()`，两侧统一补尾斜杠后比较，消除
前缀歧义。

## 影响评估

**低** — 块放置路径正确性：仅在存在 rack 命名互为前缀（rack1/rack11）且用
排除节点/scope 的集群触发，命中时 addBlock 失败重试。

## apply 检查结果

**冲突**：`DFSNetworkTopology.java`（chooseRandomWithStorageType 区与 3.1.1
上下文不同，需手工合并）。
