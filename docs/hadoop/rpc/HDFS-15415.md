# HDFS-15415 — Reduce locking in Datanode DirectoryScanner

## Commit

- **Hash**: `4a8b59df595`
- **日期**: 2020-09-30
- **涉及文件**: `hadoop-hdfs/.../datanode/DirectoryScanner.java`（+70/-73）

## Diff 机制分析

DirectoryScanner 的扫描分三步：磁盘枚举（reconcile 前）、与内存 replica map 对比、提交差异。旧实现把多步都压在 `FsDatasetImpl` 的大锁（DatasetLock）里做，扫描大磁盘时长期持锁，阻塞写 pipeline 的 addReplica/deleteReplica。修复把磁盘文件系统枚举移出数据集锁（扫描结果先落到本地集合），持锁段只做内存对比与提交，显著缩短持锁时间。

## 影响评估

**中**。DirectoryScanner 默认 6 小时跑一轮，但一轮持锁时间在大 DN 上可达分钟级，期间写路径被阻塞；缩短持锁直接改善 DN 写 RPC/写 pipeline 的尾延迟。

## apply 检查结果

**冲突**：`DirectoryScanner.java` patch does not apply（与 3.1.1 漂移，需与 HDFS-15583/15621 系列一起人工合入）。
