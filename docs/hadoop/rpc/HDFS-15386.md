# HDFS-15386 — ReplicaNotFoundException keeps happening in DN after removing multiple DN's data directories

## Commit

- **Hash**: `f701d7bdd18`
- **日期**: 2020-06-05
- **涉及文件**: `hadoop-hdfs/.../datanode/fsdataset/impl/FsDatasetImpl.java`（+5/-4）；测试 `TestFsDatasetImpl`

## Diff 机制分析

一次性移除多个数据目录（volume）时，`removeVolumes` 的副本清理循环在第一个缺失 replica 处抛 ReplicaNotFoundException 即中断，后续 volume 的 replica 未清理；这些残留 replica 仍被内存 map 引用，之后每次 block report / IBR 都会再抛 ReplicaNotFoundException，日志无限刷。修复让清理循环对单个 replica 缺失容错（记录后继续），保证全部 volume 清理完成。

## 影响评估

**中**。触发后 DN 侧永久刷异常、block report 不可靠；属运维操作（删目录）后的稳定性修复。
