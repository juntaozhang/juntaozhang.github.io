# HDFS-14610. HashMap is not thread safe (storageMap)

## Commit
- Hash: d95dd33ea11（2019-07-01）
- 文件: hadoop-hdfs-project/hadoop-hdfs/src/main/java/org/apache/hadoop/hdfs/server/blockmanagement/DatanodeDescriptor.java

## Diff 机制分析
`DatanodeDescriptor.storageMap` 通常由 storageMap 对象自身的 synchronized 保护，但 `getStorageInfo`（或其调用点）有一处读取未在 synchronized 块内。patch 把该访问纳入同步范围（+5/-2）。

## 影响评估
中。DatanodeDescriptor 在 DN 心跳与块汇报路径上被 NN 多线程并发访问，未同步读 HashMap 在扩容期可能死循环（JDK7）或读到不一致状态导致 NN 误判 DN 容量/剩余空间。典型小补丁修真实竞态，建议 cherry-pick。
