# HDFS-13736 — BlockPlacementPolicyDefault can't choose favored nodes when prefer-local-node=false

## Commit

- **Hash**: `9956d18129c55f0b95c7a26f370e94be252883a6`
- **Date**: 2019-11-01
- **涉及文件**: `hadoop-hdfs/.../blockmanagement/BlockPlacementPolicyDefault.java`（+测试）

## Diff 机制分析

 favored node 路径（客户端 `setFavoredNodes`）复用 `chooseLocalStorage`，
该方法的本地优先分支被 `preferLocalNode && ...` 门控——当
`dfs.namenode.block-placement-policy.default.prefer-local-node=false` 时，
favored node 即使在线健康也永远选不上，静默退化为随机放置。
修复：抽出 `chooseLocalOrFavoredStorage(..., isFavoredNode, ...)`，门控条件改为
`(preferLocalNode || isFavoredNode)`，favored node 不受 prefer-local 开关影响。

## 影响评估

**低** — 放置策略正确性：仅影响关闭 prefer-local 且使用 favored nodes 的集群
（如 HBase 类场景），修复其 favored node 失效问题。

## apply 检查结果

**clean**。
