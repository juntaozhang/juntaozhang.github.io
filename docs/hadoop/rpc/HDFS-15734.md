# HDFS-15734 — [READ] DirectoryScanner#scan need not check StorageType.PROVIDED

## Commit

- **Hash**: `09bbbc8b866`
- **日期**: 2021-02-22
- **涉及文件**: `hadoop-hdfs/.../datanode/DirectoryScanner.java`（+1/-2）

## Diff 机制分析

DirectoryScanner 扫描循环里原本对每个 ScanInfo 都查 `vol.getStorageType() == StorageType.PROVIDED` 来跳过 Provided 存储；由于一个 volume 的 StorageType 在扫描期内不变，逐条检查是重复开销。改为在循环外判断一次、对 Provided 卷整体跳过。微小优化。

## 影响评估

**低**。仅省一次枚举比较，常规集群（无 Provided 存储）收益可忽略；属于顺手的清理，跟随 DirectoryScanner 系列补丁一起合入成本低。

## apply 检查结果

**冲突**：`DirectoryScanner.java` patch does not apply（该文件在 3.1.1 与上游间已有多个 DirectoryScanner 补丁漂移，需与 HDFS-15415/15583 一并人工合入）。
