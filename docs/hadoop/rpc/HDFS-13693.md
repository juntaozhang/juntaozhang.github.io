# HDFS-13693 — Remove unnecessary search in INodeDirectory.addChild during image loading

## Commit

- **Hash**: `8ce5015e94bd973c9e888342117267f14059944f`
- **Date**: 2019-07-23
- **涉及文件**: `FSImageFormatPBINode.java`、`INodeDirectory.java`

## Diff 机制分析**

fsimage 加载时 `addToParent` 调 `parent.addChild(child)`，后者在子节点 map 里
做一次二分查找定位插入点（按序列化顺序加载时插入点恒为末尾，查找纯属浪费，
大目录多时加载明显变慢）。修复：新增 `addChildAtLoading()`——非 reference
节点直接追加到 children 末尾（pos = -size-1 语义），reference 节点走原路径；
序列化侧补注释要求 children 保序。

## 影响评估

**低** — NN 启动 fsimage 加载性能优化（大 fsimage 可观），不影响稳态 RPC。

## apply 检查结果

**冲突**：`FSImageFormatPBINode.java`（addToParent 区与 3.1.1 上下文不同，
需手工合并；`INodeDirectory.java` 干净）。
