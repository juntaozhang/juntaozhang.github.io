# HDFS-15281 — Make sure ZKFC uses dfs.namenode.rpc-address to bind to host address

## Commit

- **Hash**: `68dcdad6662`
- **日期**: 2020-04-25
- **涉及文件**: `hadoop-common/.../ha/ZKFailoverController.java`、`hdfs/tools/DFSZKFailoverController.java`；测试 `TestDFSZKFailoverController`

## Diff 机制分析`

多网卡机器上 ZKFC 向 ZK 注册/检查 NN 健康时绑定地址不按 `dfs.namenode.rpc-address` 配置的主机解析，导致 ZKFC 绑错网卡地址、health check/fencing 指向错误地址，failover 失败。修复让 DFSZKFailoverController 显式从 namenode rpc-address 取主机用于绑定与健康检查目标。

## 影响评估

**低**。仅多网卡 + 显式绑定地址配置的 HA 集群受影响；命中时 failover 不可用，属正确性修复。

## apply 检查结果

**clean**。
