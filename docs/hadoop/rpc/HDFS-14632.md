# HDFS-14632. Reduce useless #getNumLiveDataNodes call in SafeModeMonitor

## Commit
- Hash: 2e1afa9a867（2019-07-10）
- 文件: BlockManagerSafeMode.java, TestBlockManagerSafeMode.java, TestHASafeMode.java 等

## Diff 机制分析
SafeModeMonitor 每次运行（默认 3s 周期）重复调用 `getNumLiveDataNodes` 多次，每次都遍历全部 DatanodeDescriptor。patch 改为每轮计算一次并复用（+22/-12）。NN 有数千 DN 时，safemode 检查是纯读锁内遍历，缩短 readLock 持有时间。

## 影响评估
低。纯小优化：降低 safemode 周期检查的开销与 fslock 读锁占用，对启动/退出 safemode 阶段略有帮助。风险低，可顺手 cherry-pick。
