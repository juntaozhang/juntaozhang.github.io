# HDFS-14582. Failed to start DN with ArithmeticException when NULL checksum used

## Commit
- Hash: c2aeeb01fa6（2019-08-20）

## Diff 机制分析
块使用 NULL checksum（不校验，部分测试/特殊场景）时，BlockPoolSlice 计算块大小/校验和的除法路径除以 0 抛 ArithmeticException，导致 DN 启动加载块池失败。patch 加 5 行对 null/零值 checksum 的保护。

中。导致 DN 无法启动的可用性问题，虽不常见但一旦发生需人工介入。修复极小，但冲突在 BlockPoolSlice.java，需手工合并。
