# HDFS-14706. Checksums are not checked if block meta file is less than 7 bytes

## Commit
- Hash: 63b18d764ae（2019-09-02）
- 文件: DataChecksum.java, BlockMetadataHeader.java, CorruptMetaHeaderException.java, BlockSender.java, DataNode.java, DataXceiver.java（7 个文件，含 165 行测试）

## Diff 机制分析
块 meta 文件小于 7 字节（版本+checksum头最小长度）时，原代码读取 header 后直接走"无 checksum"路径，跳过校验和验证，损坏的 meta 被当成 valid，块数据被当作不需校验读取。patch 引入 `CorruptMetaHeaderException`，对过短的 meta header 视为损坏块并走 corrupt block 上报路径。

## 影响评估
中。这是静默数据完整性问题：meta 文件截断/损坏时客户端读到未校验数据且不报 corruption，违背 HDFS 端到端校验承诺。修复使短 meta 块被正确识别并修复/删除。冲突在 DataNode.java，需手工合并。
