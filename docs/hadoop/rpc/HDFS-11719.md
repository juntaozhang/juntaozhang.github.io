# HDFS-11719 — BlockSender.readChecksum 异常处理中 Arrays.fill 下标错误

## Commit

- **Hash**: `bff22305911`（branch-3.1，2018-09-18，Tao Zhang）
- **涉及文件**（1 个，+4/-3）：`BlockSender.java`

## Diff 机制分析

`BlockSender.readChecksum` 读校验和出错且 `corruptChecksumOk`（下游允许坏校验和，如 LocalReplica 某些路径）时，要把输出 buffer 的校验和区域清零。原代码：

```java
if (checksumOffset < checksumLen) {
  Arrays.fill(buf, checksumOffset, checksumLen, (byte)0);
```

两个 bug：(1) 条件 `checksumOffset < checksumLen` 在 offset 大于 len 时本应清零却不零；(2) `Arrays.fill(buf, from, to)` 的 `to` 是绝对下标，原代码把 `checksumLen`（长度）当结束下标，当 `checksumOffset > 0` 时**清不到应有的长度**（甚至 `to < from` 时 fill 本身按实现可能什么都不做/抛异常取决于 JDK）。

修复：条件改 `checksumLen > 0`，fill 范围改 `(buf, checksumOffset, checksumOffset + checksumLen)`。

代码路径：DN `BlockSender` 发送 checksum（每读一个 checksum chunk 一次，READ_BLOCK 热路径的异常分支）。

## 影响评估

**评级：低**。仅影响"容忍坏校验和"读路径的异常分支；修复后坏 checksum 块的降级读取行为正确。
