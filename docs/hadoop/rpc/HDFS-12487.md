# HDFS-12487 — FsDatasetSpi.isValidBlock 空指针检查缺失

## Commit

- **Hash**: `4507c2f3a5d`（branch-3.1，2019-06-21，liumi）
- **涉及文件**（1 个，+5/-1）：`DiskBalancer.java`

## Diff 机制分析

branch-3.1 backport 只含 DiskBalancer 部分：`DiskBalancer.getBlockToCopy()` 遍历 `BlockIterator` 时，改动前对 `iter.nextBlock()` 的返回值直接判 `block != null`，但 `getBlockToCopy` 外层 `while (!iter.atEnd() && ...)` 循环内 `iter.nextBlock()` 返回 null 时，后续 `isValidBlock(block)` 调用链仍以 null 进入 → NPE。

修复：在 `iter.nextBlock()` 后立即判 null，null 则记录日志并返回（结束本次拷贝选择）。

代码路径：DiskBalancer `moveBlock` 线程 → `getBlockToCopy` → `FsVolumeSpi.BlockIterator`。JIRA 原意还覆盖 `isValidBlock` 及其调用方的 NPE 防护。

## 影响评估

**评级：低**。仅影响 DiskBalancer 执行路径（运维触发的磁盘均衡操作），不影响正常读写 RPC；但 DiskBalancer 运行时 NPE 会导致均衡任务静默失败。
