# HDFS-14952 — Skip safemode if blockTotal is 0 in new NN

## Commit

- **Hash**: `d101b748142969e7b3b9de442884f71d7f7304f2`
- **Date**: 2019-11-19
- **涉及文件**: `BlockManagerSafeMode.java`（+2 个测试）

## Diff 机制分析

全新 NN（首次格式化、无 block report）blockTotal=0，但 safemode 状态机仍会进
EXTENSION 分支并 `timeToLeaveExtension()` 干等默认 30 秒 extension 期，
空集群每次重启白白多等半分钟。修复：`blockTotal > 0` 才允许 PENDING_THRESHOLD→
EXTENSION；`timeToLeaveExtension()` 在 blockTotal=0 时直接返回 0。

## 影响评估

**低** — NN 启动可用性：仅影响新集群/空集群启动速度（省 30s），对已有数据集群无影响。

apply 干净，测试可按需跳过）。
