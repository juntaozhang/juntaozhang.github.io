# HDFS-14578 — AvailableSpaceBlockPlacementPolicy always prefers local node

## Commit

- **Hash**: `12b258115b49bf781615194429da7dd19d3e916e`
- **Date**: 2020-01-11
- **涉及文件**: `DFSConfigKeys.java`、`AvailableSpaceBlockPlacementPolicy.java`、`hdfs-default.xml`（+测试）

## Diff 机制分析

AvailableSpaceBlockPlacementPolicy 本应优先把副本放到磁盘最空的节点，但其继承的
`chooseLocalStorage()` 无条件优先本地节点，本地盘满的节点也照写，破坏策略初衷。
修复：覆写 `chooseLocalStorage()`，新增配置
`dfs.namenode.available-space-block-placement-policy.balance-local-node`（默认 false
保持原行为）；开启后先各取 local/localRack 候选，用 `select(..., isBalanceLocal=true)`
比较使用率（本地节点 dfsUsed<50% 时视为平局优先本地），实现"空间优先、兼顾本地"。

## 影响评估

**低** — 仅对显式启用 AvailableSpace 放置策略的集群有意义；修复其永远偏向本地
节点导致的节点间空间失衡。
