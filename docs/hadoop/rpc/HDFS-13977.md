# HDFS-13977. Override shouldForceSync in QuorumOutputStream to allow for proper auto-sync behavior

## Commit
- Hash: 9dc921f5e5d（2019-08-16）
- 文件: QuorumOutputStream.java, QuorumJournalManager.java, FSEditLog.java（5 个文件含测试）

## Diff 机制分析
`EditLogOutputStream.shouldForceSync()` 默认实现让 FSEditLog 认为 QJM 输出流需要每事务 force sync，导致 `logSync` 路径上的自动批处理/延迟 sync 优化失效。patch 在 QuorumOutputStream 覆写该方法返回 false，使 QJM 走正确的 auto-sync 行为，减少不必要的 journal 同步往返。

## 影响评估
中。修复后 active NN 的 edit log 批量提交路径减少多余的 sync 等待，直接降低 QJM 写入延迟与 JN RPC 压力。对写密集型 NN 有吞吐收益，冲突在 QuorumJournalManager.java，需手工合并。
