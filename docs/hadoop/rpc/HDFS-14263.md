# HDFS-14263 — 移除 getBlockInputStream 中多余的 block 文件存在性检查

## Commit

- **Hash**: `bd9e2826fec`（branch-3.1，2019-02-13，Surendra Singh Lilhore）
- **涉及文件**（1 个，+1/-1）：`FsDatasetImpl.java`

## Diff 机制分析

`FsDatasetImpl.getBlockInputStream`（DataXceiver 读 block 路径）原实现：

```java
if (info != null && info.blockDataExists()) { ... }
```

`info` 来自 `volumeMap.get(bpid, blockId)`，**能进 volumeMap 的 replica 必然在磁盘扫描时已确认数据文件存在**；`blockDataExists()` 每次读都额外做一次磁盘 `File.exists()` 系统调用。高并发读时这个 syscall 是纯浪费（且磁盘故障时 exists() 可能误报 false，把可读 block 误判为不存在）。

修复：去掉 `blockDataExists()` 检查，`info != null` 即返回数据流。

代码路径：DataXceiver `READ_BLOCK` / 短读校验 → `FsDatasetImpl.getBlockInputStream`（DN 读热路径，每读每块一次）。

## 影响评估

**评级：低**。每次块读省一次 stat syscall；读密集型 DN 有微小但累积的 I/O 收益，并消除误判。
