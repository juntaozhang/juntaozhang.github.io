# HDFS-13791. Limit logging frequency of edit tail related statements

## Commit
- Hash: 91803c82167（2018-09-27）
- 文件: LogThrottlingHelper.java（新增）, QuorumJournalManager.java, FSEditLogLoader.java, FSImage.java, RedundantEditLogInputStream.java

## Diff 机制分析
NN 启动/failover 恢复加载 edits 时，"无法从某流读取"等 warn 日志按事务数逐条打印，大 edits 下刷出百万行日志（IO 风暴拖慢启动）。patch 新增 LogThrottlingHelper 通用节流工具，对 FSEditLogLoader/FSImage/RedundantEditLogInputStream/QJM 的关键日志做限频。

## 影响评估
低。不改逻辑只限频，但大集群 NN 重启/failover 时日志风暴是真实的启动耗时放大器，且可能写爆磁盘。需手工引入新文件 LogThrottlingHelper.java（3.1.1 无此类），其余文件冲突在 QuorumJournalManager.java。
