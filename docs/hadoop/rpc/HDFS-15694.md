# HDFS-15694 — Avoid calling UpdateHeartBeatState inside DataNodeDescriptor

## Commit

- **Hash**: `2331f86dfba`
- **日期**: 2020-12-01
- **涉及文件**: `hadoop-hdfs/.../blockmanagement/DatanodeDescriptor.java`（+6/-2）

## Diff 机制分析

`DatanodeDescriptor` 内部多处调用 `updateHeartBeatState` 时隐式携带/更新存储统计，造成心跳处理路径上重复的状态计算与多余的集合操作。修复把 heartbeat 状态更新收敛到明确入口（heartbeat 处理处一次完成），`DatanodeDescriptor` 内不再自行触发。改动在 NN 心跳处理热路径上减少锁内工作。

## 影响评估

**中**。心跳是 NN 最频繁的入口之一（默认 3s × DN 数量），减少锁内重复计算对大集群（数千 DN）的 NameNode RPC 处理开销有累积收益；属性能优化非 bug 修复。

## apply 检查结果

**clean**。
