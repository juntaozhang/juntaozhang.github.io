# HDFS-15074 — DataNode.DataTransfer thread should catch all exceptions

## Commit

- **Hash**: `55510d32bf09a4a3cdeabac6f5825dde648260f7`
- **Date**: 2019-12-29
- **涉及文件**: `hadoop-hdfs/.../server/datanode/DataNode.java`

## Diff 机制分析

`DataTransfer.run()` 只 catch `IOException`；block 复制/重建传输中若抛出
RuntimeException/Error（如 NPE、断言），异常直接逃出 run()，线程无声死亡且
`decrementXmitsInProgress()` 在 finally 中虽执行，但上层无法感知传输真实结果——
NN 侧 pending 状态需等超时回收，且异常无任何日志，现场无法诊断。
修复：补 `catch (Throwable t) { LOG.error(...) }`，与同类线程（PacketResponder 等）
的防御风格一致。

## 影响评估

**低** — DN 复制线程健壮性：两行的防御性修复，消除线程无声死亡和无日志故障。

## apply 检查结果

**冲突**：`DataNode.java`（transfer 方法周边上下文与 3.1.1 有差异，需手工合并）。
