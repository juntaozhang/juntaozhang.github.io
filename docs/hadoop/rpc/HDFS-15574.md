# HDFS-15574 — Remove unnecessary sort of block list in DirectoryScanner

## Commit

- **Hash**: `43b113de69a`
- **日期**: 2020-09-17
- **涉及文件**: `DirectoryScanner.java`、`FsDatasetSpi.java`、`FsDatasetImpl.java`（+50/-14）；测试若干

## Diff 机制分析

DirectoryScanner 拿到 FsDataset 的 replica 列表后先整体排序再逐项比对，而后续比对用 HashMap 查找，排序纯属浪费（O(n log n) 且 comparator 有 I/O 级字符串比较）。修复移除排序，`getBlockReport`/相关接口签名去掉排序要求。

## 影响评估

**低**。每次扫描省一次全量排序，大 DN 上缩短扫描窗口与 CPU 占用；无行为变化。

## apply 检查结果

**clean**。
