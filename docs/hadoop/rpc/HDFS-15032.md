# HDFS-15032 — ProxyCombiner should unwrap InvocationTargetException

## Commit

- **Hash**: `b06965ae32c4be2e6923a2f057290fbdbda5f38a`
- **Date**: 2019-12-04
- **涉及文件**: `hadoop-common/.../ipc/ProxyCombiner.java`（+测试）

## Diff 机制分析

`ProxyCombiner` 的 CombinedProxyInvocationHandler.invoke 用反射 `method.invoke()`
逐个代理调用。被调代理抛业务异常时反射包装为 InvocationTargetException，
原代码只 catch IllegalAccess/IllegalArgument，ITE 直接向外抛，调用方（如 balancer
通过 HA proxy 调 getBlocks）收到的是包装异常而非原始 IOException 语义，
重试/故障转移逻辑按异常类型判断全部失灵。
修复：catch `InvocationTargetException` 并 `throw ite.getCause()`，还原原始异常。

## 影响评估

**低** — hadoop-common IPC proxy 框架的异常语义修正：凡经 ProxyCombiner 的
RPC（HA 下 balancer/mover 等）异常处理恢复正常；非该路径无影响。
