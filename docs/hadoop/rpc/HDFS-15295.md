# HDFS-15295 — AvailableSpaceBlockPlacementPolicy should use chooseRandomWithStorageTypeTwoTrial() for better performance

## Commit

- **Hash**: `6f7a30fd716`
- **日期**: 2020-04-24
- **涉及文件**: `hadoop-hdfs/.../blockmanagement/AvailableSpaceBlockPlacementPolicy.java`（+2/-2）

## Diff 机制分析

基于可用空间的选择策略每选一个 block 目标都做一次全机架随机选取 + 排序比较；trunk 上 `NetworkTopology` 已提供 `chooseRandomWithStorageTypeTwoTrial()`（先本地机架两次尝试再 fallback，省全拓扑扫描）。修复让该策略改用 two-trial 接口，选择目标从全局扫描降为常数级尝试。

## 影响评估

**低**。仅使用 AvailableSpace（或继承）放置策略的集群受益，写路径 block placement 的 CPU 开销下降；无语义变化。

## apply 检查结果

**冲突**：`AvailableSpaceBlockPlacementPolicy.java` patch does not apply（3.1.1 中该策略实现较老，需先确认 two-trial 接口在 3.1.1 基线是否存在再合入）。
