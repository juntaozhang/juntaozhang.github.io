# HDFS-14043 — 容忍损坏的 seen_txid 文件

## Commit

- **Hash**: `9bf4f3d6140`（branch-3.1，2018-11-05，Lukas Majercak）
- **涉及文件**（2 个，+58/-2）：`PersistentLongFile.java`、测试

## Diff 机制分析

`PersistentLongFile.readFile` 读取写入 `seen_txid` 等持久化长整型文件。文件内容损坏（磁盘位翻转、不完整写入）时 `Long.parseLong` 抛 `NumberFormatException`（RuntimeException）——**穿透** 了方法的 `throws IOException` 契约，调用方（NN/DN 存储恢复）按 IOException 处理的路径捕获不到，异常以未包装形式上抛，进程启动失败且报错信息混乱。

修复：捕获 `NumberFormatException` 包装为 `IOException` 抛出，调用方按既有 IOException 路径（回退默认值/重新初始化）处理。

代码路径：NN/DN/JN 启动 → `Storage`/`NNStorage`/`FileJournalManager` 读 `seen_txid`。

## 影响评估

**评级：低**。罕见磁盘损坏场景的启动容错改进；无稳态性能影响。
