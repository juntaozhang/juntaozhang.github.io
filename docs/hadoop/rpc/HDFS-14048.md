# HDFS-14048 — DFSOutputStream 在 DN 重启后 close() 抛异常

## Commit

- **Hash**: `f65324aa47e`（branch-3.1，2018-11-06，Erik Krogen）
- **涉及文件**（2 个，+3/-1）：`DataStreamer.java`（hadoop-hdfs-client）、测试

## Diff 机制分析

`DataStreamer.createBlockOutputStream` 建管道成功后，原代码重置了 `errorState` 但**没有清 `lastException`**。当 DN 重启导致之前管道失败（`lastException` 记录了 SocketException 等）后，如果后续 `close()` 期间 `DataStreamer.close` 的 `lastException.check` 逻辑再检查到非空 lastException，会在**文件已成功写完**的情况下仍向用户抛异常（"Failed to close" 类错误，带早先的 DN 重启异常）。

修复：管道建立成功路径上 `lastException.clear()`。

代码路径：DFSOutputStream 写 → 管道恢复/重建（DN 重启场景）→ `createBlockOutputStream` 成功 → `close()`。

## 影响评估

**评级：中**。客户端写路径在 DN 故障恢复后的假错误：上层应用（HBase WAL flush 等）收到误导性异常并可能重试/报错。属于客户端写路径稳定性修复。
