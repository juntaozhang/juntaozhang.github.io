# HDFS-13721 — DataNode 因 DiskBalancer 未初始化而 NPE

## Commit

- **Hash**: `7d1e2e1fbbe`（branch-3.1，2018-07-06，Xiao Chen）
- **涉及文件**（2 个，+18/-6）：`DataNode.java`、测试

## Diff 机制分析

`diskBalancer` 字段在 `initBlockPool` 成功后才赋值。在此之前（或 block pool 初始化失败路径），以下入口都直接解引用 `this.diskBalancer` → NPE：

- JMX `getDiskBalancerStatus()`（DataNodeMXBean，监控系统随时调）；
- RPC `submitDiskBalancerPlan` / `cancelDiskBalancePlan` / `queryDiskBalancerPlan` / `getDiskBalancerSetting`（`DatanodeProtocol` 管理 RPC）。

修复：新增 `getDiskBalancer()` 私有方法，null 时抛带明确信息的 `IOException("DiskBalancer is not initialized")`；全部入口改走该方法（JMX getter 原有 try-catch 吃掉异常返回空串）。

代码路径：DN 启动早期 / block pool 注册失败后的窗口期；JMX 轮询与管理 RPC。

## 影响评估

**评级：低**。NPE → 明确异常的服务端健壮性修复；影响 DN 启动窗口期的 JMX/管理 RPC。
