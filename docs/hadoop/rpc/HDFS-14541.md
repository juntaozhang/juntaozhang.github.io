# HDFS-14541. When evictableMmapped or evictable size is zero, do not throw NoSuchElementException

## Commit
- Hash: aaf74ea5d73（2019-06-24）
- 文件: ShortCircuitCache.java（+11/-29）

## Diff 机制分析
ShortCircuitCache 驱逐线程对 `evictableMmapped`/`evictable` 队列轮询时，队列大小与 poll 之间存在竞态（检查后变 0），`remove()` 抛 NoSuchElementException 杀死驱逐/缓存线程。patch 改用 poll 空值判断，并顺带简化移除逻辑（+11/-29）。

## 影响评估
低-中。影响短路读缓存的稳定性：驱逐线程死后短路读缓存退化（短期读回退到普通读路径，有性能影响）。修复并发竞态，建议 cherry-pick。
