# HDFS-13101. Yet another fsimage corruption related to snapshot

## Commit
- Hash: d18b720c705（2019-08-15）
- 文件: INode.java, INodeDirectory.java, INodeFile.java, AbstractINodeDiffList.java, DirectoryWithSnapshotFeature.java, FileWithSnapshotFeature.java（8 个文件含测试）

## Diff 机制分析
快照目录/文件的 diff list 在 save/load fsimage 时，snapshot 引用计数与 diff 序列化顺序不一致：加载时先构造 feature 后恢复引用，期间出现"引用已释放但 diff 仍存在"的窗口，保存出的 fsimage 中 inode 的 snapshot 元数据损坏，load 后抛异常或数据错乱。patch 调整 fsimage 序列化/反序列化顺序并增加一致性检查（+168/-9）。

## 影响评估
高。直接造成 fsimage 文件损坏，重启无法加载，影响启用 snapshot 的集群，属数据层损坏级 bug。修复附带一致性校验，建议有 snapshot 使用的集群务必 cherry-pick。
