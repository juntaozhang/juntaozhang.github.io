# HDFS-15293 — Relax the condition for accepting a fsimage when receiving a checkpoint

## Commit

- **Hash**: `8f53545f9d1`
- **日期**: 2020-05-18
- **涉及文件**: `hadoop-hdfs/.../namenode/ImageServlet.java`（+39/-11）；测试 `TestCheckpoint`

## Diff 机制分析`

Active NN 接收 SBN/2NN 上传 fsimage 的校验中，"距上次 checkpoint 的时间差"一项按完整 checkpoint period 判断，忽略了上传耗时与机器间 minor clock skew，导致合法的 checkpoint 被 409 拒绝、SBN checkpoint 流程失败重试。修复引入 0.75 的时间精度系数放宽时间差校验，并改进拒绝信息的日志。

## 影响评估

**低**。HA checkpoint 偶发失败的修复；属 HTTP 传输层，但承载 SBN→ANN 的 fsimage 通道，对 checkpoint 频繁的集群有意义。

## apply 检查结果

**冲突**：`ImageServlet.java`、`TestCheckpoint.java` patch does not apply（需人工合入，核心改动是新增精度系数常量与校验式调整）。
