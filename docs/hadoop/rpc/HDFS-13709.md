# HDFS-13709. Report bad block to NN when transfer block encounter EIO exception

## Commit
- Hash: fc062b6fef9（2019-08-19）
- 文件: BlockSender.java, DataNode.java, DiskFileCorruptException.java, VolumeScanner.java 等（7 个文件含 111 行测试）

## Diff 机制分析
DN 间块传输（balance/recovery 读源块）遇到磁盘 EIO 时，原来只把异常抛给调用方，不报告坏块，NN 永远不知道该副本已坏。patch 引入 `DiskFileCorruptException`，读路径捕获 EIO 后经 DataNode.reportBadBlocks 上报 NN，触发副本修复；VolumeScanner 同步适配。

## 影响评估
中。提升坏盘/坏块发现速度：原来只能靠客户端读触发或 VolumeScanner 周期扫描发现，现在副本迁移路径即可上报，缩短 under-replicated/数据丢失暴露窗口。建议 cherry-pick。
