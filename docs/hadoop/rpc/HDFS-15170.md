# HDFS-15170 — EC: Block gets marked as CORRUPT in case of failover and pipeline recovery

## Commit

- **Hash**: `a09d636e2cd`
- **日期**: 2020-12-14
- **涉及文件**: `hadoop-hdfs/.../blockmanagement/BlockManager.java`（+10）；测试 `TestErasureCodingCorruption`

## Diff 机制分析

EC block group 在 failover 与 pipeline recovery 并发时，DN 上报的旧 generation stamp 块被 Standby 误判为 CORRUPT（同 HDFS-15187 一族，特定于 EC 块组的内部块）。修复在 BlockManager 的 corrupt 判定中增加对 EC 内部块恢复中状态的豁免：处于 RUR/recovery 状态的块不直接标 CORRUPT，走延迟队列待状态稳定后再判。

## 影响评估

**中**。EC 集群 failover 后可能整组块被误标 CORRUPT，触发无意义的重建与告警；正确性修复，非热路径。
