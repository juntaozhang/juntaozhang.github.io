# HDFS-15250 — Setting dfs.client.use.datanode.hostname to true can crash the system because of unhandled UnresolvedAddressException

## Commit

- **Hash**: `86c15b82874`
- **日期**: 2020-05-10
- **涉及文件**: `hadoop-hdfs-client/.../client/impl/BlockReaderFactory.java`（+2/-1）

## Diff 机制分析`

开启 `dfs.client.use.datanode.hostname`（跨网段/多机房客户端按主机名连 DN）后，DN 主机名解析失败时 `BlockReaderFactory` 创建 socket 抛 UnresolvedAddressException 未处理，客户端 JVM 直接 crash（未捕获异常）。修复捕获并包装为 IOException 走既有重试/报错位。

## 影响评估

**中**。使用 hostname 模式的客户端（云/跨机房部署常见）在 DNS 抖动时直接进程崩溃；一行修复。

## apply 检查结果

**clean**。
