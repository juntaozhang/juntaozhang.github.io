# HDFS-15618 — Improve datanode shutdown latency

## Commit

- **Hash**: `33db7c140b3`
- **日期**: 2020-10-22
- **涉及文件**: `DFSConfigKeys.java`、`BlockScanner.java`、`DataNode.java`、`VolumeScanner.java`、`VolumeScannerCBInjector.java`、`hdfs-default.xml`；测试若干

## Diff 机制分析

DN 优雅停机时要等 VolumeScanner 当前扫描文件收尾，而大文件扫描 + 节流读使停机被拖到分钟级。修复：1) BlockScanner/VolumeScanner 增加可中断的扫描循环，shutdown 标志置位后当前文件读取即中止；2) 新增 `dfs.datanode.block.scan.threads` 等相关配置控制；3) DataNode 停机序列先停 scanner 再关 IPC。

## 影响评估

**低**。只影响 DN 停机/重启耗时（滚动升级、维护窗口更快），不影响运行期 RPC 性能；对大规模集群滚动运维有实际价值。
