# HDFS-15622 — Deleted blocks linger in the replications queue

## Commit

- **Hash**: `7a3085d552c`
- **日期**: 2020-10-22
- **涉及文件**: `hadoop-hdfs/.../blockmanagement/LowRedundancyBlocks.java`；测试 `TestLowRedundancyBlockQueues`、`TestReplicationPolicy`

## Diff 机制分析`

文件被删除后其 block 应从低冗余队列（corrupt/underReplicated 等 5 个优先级队列）中移除；旧实现 `remove` 只在部分队列分支做清理，导致已删块残留在某优先级队列里，redundancy 线程反复为它调度无效复制任务（每次都因 block 不存在而失败重试），白白消耗 NN 锁内时间和调度队列长度。修复统一各队列的移除语义，确保删除时从所有队列清除。

## 影响评估

**中**。表现为 replication 队列长期虚高、NN 冗余调度做无用功；对删除频繁的大集群有可观测的 NN 负载收益。正确性+性能双重收益。
