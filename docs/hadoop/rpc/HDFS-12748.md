# HDFS-12748. NameNode memory leak when accessing webhdfs GETHOMEDIRECTORY

## Commit
- Hash: 9c3806cf1b7（2019-07-11）
- 文件: DFSUtilClient.java, DistributedFileSystem.java, NamenodeWebHdfsMethods.java

## Diff 机制分析
WebHdfs 的 GETHOMEDIRECTORY 每次请求都在 NN 上新建一个带独立 UGI/缓存的 FileSystem 实例且不复用 cache（DistributedFileSystem.getHomeDirectory 实现路径导致 cache key 每次不同），GC 回收不掉关键引用，内存持续增长。patch 在 DFSUtilClient 增加统一的 home directory 解析，避免在 NN 进程内重复创建 FS 实例。

## 影响评估
中。NN 堆内存泄漏：任何周期性打 GETHOMEDIRECTORY 的客户端（部分 SDK/网关）都会让 NN 缓慢 OOM。修复在客户端工具方法+webhdfs 方法，建议 cherry-pick。
