# HDFS-15709 — Socket file descriptor leak in StripedBlockChecksumReconstructor

## Commit

- **Hash**: `173d298c637`
- **日期**: 2020-12-08
- **涉及文件**: `hadoop-hdfs/.../datanode/BlockChecksumHelper.java`、`StripedBlockChecksumReconstructor.java`

## Diff 机制分析

EC 文件的 striping checksum 计算（`getFileChecksum` 路径，客户端对 EC 文件算校验和时 DN 侧触发）中，`StripedBlockChecksumReconstructor` 向其它 DN 拉取内部块做重建计算，异常路径上 socket/DataInputStream 未被关闭，FD 随每次调用泄漏。修复重构 try/finally 确保重建器、socket 流在使用完毕或异常时统一关闭，并把重建器生命周期管理收敛到 `BlockChecksumHelper`。

## 影响评估

**中**。只在 EC 文件 checksum 计算路径泄漏 FD；高频调用（数据校验工具、distcp verify）下 DN 可能耗尽 FD 而失败。非 RPC 主路径但属稳定性修复。

## apply 检查结果

**冲突**：`StripedBlockChecksumReconstructor.java` patch does not apply（方法签名与 3.1.1 有漂移，需人工合入）。
