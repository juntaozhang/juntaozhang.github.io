# HDFS-15826 — Solve the problem of incorrect progress of delegation tokens when loading FsImage

## Commit

- **Hash**: `cab9172d2e3`
- **日期**: 2021-02-22
- **涉及文件**: `DelegationTokenSecretManager.java`、`FSImageFormatProtobuf.java`、`FSNamesystem.java`

## Diff 机制分析

加载 FsImage 恢复 delegation token 时，各 token 的 sequence number 没有被汇总到 `DelegationTokenSecretManager` 的当前 max id（`updatePersistedToken` 路径漏了更新），导致 `currentSeqNum` 停留在初始值；之后新签发的 token 序号与已加载的 token 撞号，引发 token 管理错乱/认证失败。修复在加载 token 时同步推进 `currentSeqNum`，保证新 token 序号严格大于所有已持久化 token。

## 影响评估

**低**。只在 NN 重启加载含 delegation token 的 fsimage 后出现，影响面是 token 序号冲突（可能导致 token 失效或认证异常）；非常驻热路径，但属正确性修复，重启频繁的 HA 集群建议合入。

## apply 检查结果

**clean**。
