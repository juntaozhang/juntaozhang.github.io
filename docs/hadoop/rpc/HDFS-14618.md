# HDFS-14618. Incorrect synchronization of ArrayList field (ArrayList is thread-unsafe)

## Commit
- Hash: ab7ecd6a0f1（2019-06-28）
- 文件: hadoop-hdfs-project/hadoop-hdfs/src/main/java/org/apache/hadoop/hdfs/server/blockmanagement/PendingReconstructionBlocks.java

## Diff 机制分析
`PendingReconstructionBlocks.pendingReconstructions` 内部有一个以 `pendingReconstructions` 为锁对象的 ArrayList，访问基本都在锁内，但某处遍历/修改漏加 synchronized。patch 补上该锁保护，使所有对 ArrayList 的访问一致串行化。

## 影响评估
中。这是 NN blockmanagement 核心类的并发缺陷，竞态下可抛 ConcurrentModificationException 或丢/重试 pending reconstruction 记录，直接影响块副本不足的补算可靠性。生产触发概率低但后果落在 NN 稳定性上，建议 cherry-pick。
