# HDFS-14655. Namenode crashes if one of the JN is down（QJM client 侧修复）

## Commit
- Hash: 5c058549b71（2019-09-25）
- 文件: DFSConfigKeys.java, IPCLoggerChannel.java, QuorumCall.java, QuorumJournalManager.java, hdfs-default.xml 等（7 个文件）

## Diff 机制分析
虽然挂在 [SBN Read] 名下，实际修复的是 QJM client：某台 JN 宕机后，`QuorumCall` 对失败请求的异常处理存在缺陷，个别请求被错误计入成功集合或未正确传播异常，NN 在等 quorum 时状态不一致可触发崩溃。patch 给 QuorumCall 增加正确的异常计数/传播逻辑，IPCLoggerChannel 增加对特定超时的处理，并新增 `dfs.namenode.edit.log.transfer.timeout` 相关配置。

## 影响评估
中。影响所有 QJM HA 集群（与 Observer/SBN read 无关）：单 JN 故障即可引发 NN 崩溃属于严重稳定性问题。冲突在 DFSConfigKeys.java（新增配置项位置），需手工合并，建议 HA 集群 cherry-pick。
