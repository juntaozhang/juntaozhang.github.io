# HDFS-14853. NPE in DFSNetworkTopology#chooseRandomWithStorageType() when the excludedNode is not present

## Commit
- Hash: 8cc702ad38f（2019-09-23）
- 文件: hadoop-hdfs-project/hadoop-hdfs/src/main/java/org/apache/hadoop/hdfs/net/DFSNetworkTopology.java

## Diff 机制分析
`chooseRandomWithStorageType` 在排除节点不在拓扑中时，`excludedNode` 对应的内部 map 查不到节点，后续解引用抛 NPE。patch 加 3 行 null 判断提前返回。触发场景：客户端指定 excludeNodes（如写 pipeline 失败重试）中某 DN 尚未注册/已下线。

## 影响评估
中。NPE 发生在 NN 块放置热路径上，会直接以 RuntimeException 形式使写 RPC 失败，客户端可见异常。三行修复，必须 cherry-pick。
