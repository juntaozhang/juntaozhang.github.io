# HDFS-15644 — Failed volumes can cause DNs to stop block reporting

## Commit

- **Hash**: `7f3645ec5ba`
- **日期**: 2020-10-23
- **涉及文件**: `hadoop-hdfs/.../datanode/fsdataset/impl/FsDatasetImpl.java`（+16/-12）

## Diff 机制分析

`getBlockReports` 遍历 replica map 时，遇到所属 volume 已失败/正在移除的 replica，旧代码直接 `continue` 丢弃，但更糟的是：由于提前 continue 落在 switch 之前，RUR（under recovery）等状态的 replica 也被一并跳过，导致整个 storage 的 block report 构建不完整，NN 长时间收不到该 DN 的块汇报，进而把块标记 missing。修复把"volume 缺失"检查移到 switch 之后：状态处理（含 RUR 取 original replica）照常进行，只是 add 时若无对应 builder 则记 warn 跳过。

## 影响评估

**高**。坏盘本是常态事件，此 bug 使坏盘 DN 的块汇报残缺，引发大规模误报 missing block 与额外复制，严重影响集群稳定与带宽。

## apply 检查结果

**clean**。
