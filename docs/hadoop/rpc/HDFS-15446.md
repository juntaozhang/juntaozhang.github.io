# HDFS-15446 — CreateSnapshotOp fails during edit log loading for /.reserved/raw/path

## Commit

- **Hash**: `1e0424f39a5`
- **日期**: 2020-07-04
- **涉及文件**: `hadoop-hdfs/.../namenode/FSDirectory.java`（+20）、`FSEditLogLoader.java`；测试 `TestSnapshot`

## Diff 机制分析

对 `/.reserved/raw` 下路径创建的 snapshot，其 CreateSnapshotOp 记录在 NN 重启加载 edit log 时因路径解析不到目录（raw 保留空间在加载期的 resolve 语义不同）而抛 FileNotFoundException，NN 启动失败。修复在 FSDirectory 增加对 reserved/raw 路径的 snapshot 解析支持，并让 FSEditLogLoader 走该路径。

## 影响评估

**低**。只有对 /.reserved/raw 路径建过快照且依赖 edit log 恢复的集群会中招；命中即 NN 无法启动，后果严重但场景罕见。正确性修复。

## apply 检查结果

**clean**。
