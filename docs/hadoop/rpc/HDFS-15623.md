## Diff 机制分析

`RPC.setProtocolEngine` 无条件用传入值覆盖 `rpc.engine.<protocol>` 配置，用户在配置里显式指定的自定义 engine 会被框架代码（如 protobuf helper）随后调用 setProtocolEngine 时悄悄替换掉。修复改为仅当配置中未显式指定该协议的 engine 时才写入。

## 影响评估

**低**。对未自定义 rpc engine 的集群零影响；对需要替换 RPC engine（如自定义序列化/审计代理层）的部署是正确性前提。属框架正确性修复。
