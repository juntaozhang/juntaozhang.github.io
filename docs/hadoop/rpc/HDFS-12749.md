# HDFS-12749 — DN may not send block report to NN after NN restart

## Commit

- **Hash**: `362657c1a3518d703085d0a3909c74d8a7f22c93`
- **Date**: 2019-10-21
- **涉及文件**: `hadoop-hdfs/.../server/datanode/BPServiceActor.java`

## Diff 机制分析

NN 重启后 DN `register()` 重试循环：EOFException/SocketTimeout 时睡 1s 重试，
但 catch 块不完整——未捕获的 IOException 直接逃逸出循环，BPServiceActor 进入
错误状态，注册失败导致该 actor 不再发 block report，NN 认为该 DN 无块、
进入无限期 safemode/大量块缺失告警。修复：统一 catch IOException 记日志继续
重试；同时 `processCommand` 中对 UnregisteredNode/DisallowedDatanode/
IncorrectVersion 三类 RemoteException 不再只是 warn，而是置 shouldServiceRun=false
干净退出 actor（避免半死不活的线程反复打无效命令）。

## 影响评估

**中** — DN→NN 注册链路稳定性：NN 滚动重启窗口内网络抖动可造成个别 DN
永久不上报，触发 safemode 卡住，属生产常见故障模式。
