# HDFS-14527 — Stop all DataNodes may result in NN terminate

## Commit

- **Hash**: `0160e2c97f79b373739da6c9723851811f6af1c1`
- **Date**: 2019-06-06
- **涉及文件**: `BlockPlacementPolicyDefault.java`、`BlockPlacementPolicyRackFaultTolerant.java`（+测试）

## Diff 机制分析

全部 DN 停止/失联瞬间（如集群维护同时停 DN），`getMaxNodesPerRack()` 中
`numOfRacks=0` 时未走短路分支，后续 `numOfReplicas / numOfRacks` 除零抛
ArithmeticException——异常从冗余监控线程（redundancy monitor）逃逸，
未捕获导致整个 NN 进程退出。修复：`numOfRacks == 1` 改为 `numOfRacks <= 1`，
0 rack 时同样返回默认分布，两个放置策略类同步修。

## 影响评估

**中** — NN 进程存活：大规模停 DN/网络分区时除零可终止 NN，属"低频但致命"。
