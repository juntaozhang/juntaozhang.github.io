# HDFS-14806 — Bootstrap standby may fail with in-progress tailing

## Commit

- **Hash**: `76ca86440672a7067ee582ae851c1686530c7c72`
- **Date**: 2019-11-06
- **涉及文件**: `hadoop-hdfs/.../namenode/ha/BootstrapStandby.java`（+2 个测试）

## Diff 机制分析

`hdfs namenode -bootstrapStandby` 默认沿用 `dfs.ha.tail-edits.in-progress`
配置。若该配置为 true（与 QJM 实时 tail 共用），bootstrap 期间会去 tail
in-progress edit 段，与 bootstrap 自身的全量下载+回放逻辑叠加，拿到不完整
的 edits 集而失败或数据不全。修复：bootstrap 流程内强制
`DFS_HA_TAILEDITS_INPROGRESS_KEY=false`，用高效的一次性下载代替 RPC tail。

## 影响评估

**低** — HA 运维工具正确性：只影响 standby bootstrap 操作，修一行；对运行期
RPC 无影响，但避免新 standby 初始化失败/不完整。

## apply 检查结果

**clean**。
