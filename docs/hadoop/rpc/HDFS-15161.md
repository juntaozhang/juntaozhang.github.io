# HDFS-15161 — ShortCircuitCache#close() NoSuchElementException when evictable size is zero

## Commit

- **Hash**: `83ab85373386256bf8d38d1e7259ecee7132bfa6`
- **Date**: 2020-02-12
- **涉及文件**: `hadoop-hdfs-client/.../shortcircuit/ShortCircuitCache.java`

## Diff 机制分析

`ShortCircuitCache.close()` 用 `while(true) { try { firstKey() } catch
(NoSuchElementException) { break } }` 来排空 evictable/evictableMmapped 两个
TreeMap——用异常当循环终止条件。当 map 恰好在两次操作间被并发清空、或 firstKey
与后续 purge 之间被移除时，异常语义混乱（`purge()` 自身也可能抛 NPE），
close 流程失败导致短路缓存资源（mmap 缓冲、slot）泄漏。
修复：改为标准的 `while (!map.isEmpty())` 检查 + firstKey，消灭控制流异常。

## 影响评估

**低** — 客户端短路读缓存关闭路径（进程退出/DFSClient 关闭时）的健壮性修复；
主要影响是避免资源泄漏和误导性异常日志。
