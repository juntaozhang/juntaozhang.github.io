# HDFS-14852 — Removing from LowRedundancyBlocks does not remove the block from all queues

## Commit

- **Hash**: `0f234667dde`
- **日期**: 2020-08-25
- **涉及文件**: `hadoop-hdfs/.../blockmanagement/BlockManager.java`、`LowRedundancyBlocks.java`；测试 `TestLowRedundancyBlockQueues`

## Diff 机制分析

`LowRedundancyBlocks.remove` 系列方法在按队列优先级查找块时，若块实际位于其它优先级队列（如状态在 corrupt/underReplicated 间迁移后），remove 操作落空，块残留于队列。冗余线程此后无限期重试处理这些幽灵块。修复让 remove 覆盖所有队列（与 HDFS-15622 同族，3.2 侧先行修复）。

## 影响评估

**中**。幽灵块使 replication 队列虚高、NN 周期性做无效调度；长期运行的大集群会累积该问题。

## apply 检查结果

**clean**。
